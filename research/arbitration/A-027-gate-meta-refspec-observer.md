## 3. Решение по предмету (3) — проба-наблюдатель: ПРИНЯТА с одной достройкой, предел — ноль кругов

### 3.1 Почему не вариант (в) — свернуть пробу в долг

### 3.2 Почему не вариант (а) — принять как есть

`C-184` B-1 воспроизведён мной в среде предмета: `if: ${{ false }}` ПОСЛЕ `run:` шага
дотягивания (cmp внесена) → проба **PASS (10/10), exit=0**, при том что её собственная
строка печатает «стоит ДО барьера и **безусловна**» (Done Block, Д-2). Влить это как есть —
влить оракул, который в своём PASS-тексте утверждает то, чего не меряет: буквальный класс

Долг здесь дороже фикса — редкий случай, и он назван, а не предположен.

### 3.3 Достройка — ровно одна, сформулирована мною, предел назван по образцу `П-024`

### Вопрос В — `continue-on-error`. РЕШЕНИЕ: настоящая дыра, generic, карточка долга — не блокер

Воспроизведена мной (Done Block Д-3): `continue-on-error: true` на шаге барьера → проба
PASS (10/10); агрегат (`ci.yml:523-528`) проверяет `needs.<job>.result == success`
ЕДИНООБРАЗНО для всех **14** джобов, а шаг с `continue-on-error` даёт джобу `success` при
упавшей команде. Три факта решают маршрут:

1. дыра НЕ внесена этой веткой — это свойство проводки агрегата, общее всем барьерам
   (родственно `TD-181`: «база из события» — пять барьеров, та же логика «класс шире
   предмета → долг, зона architect»);
2. она независима от спора о (3) — мандат это верно назвал;
3. её механизация — ещё один текстовый наблюдатель YAML, то есть тот же несходящийся класс,
   который это решение останавливает; строить его сейчас значило бы открыть новую серию
   кругов на соседнем предмете.

Маршрут: **карточка долга, severity MAJOR** (текст — §6), заводит reviewer при ближайшем
close-out (`П-022`: арбитр называет текст, `TECH-DEBT.md` — зона reviewer'а). Блокером
PR #125 не является. Честность требует сказать и обратное: пока карточка не заведена,
одна строка в `ci.yml` глушит ЛЮБОЙ барьер агрегата молча — бэкстоп здесь только PR-ревью
диффа `ci.yml`. Это принятый и теперь ОБЪЯВЛЕННЫЙ риск, а не молчаливый.
