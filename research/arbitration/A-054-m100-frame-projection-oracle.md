**Вывод для фикстуры `w1`:** первый кадр после `append_book(5, 3)` — НЕ вырожденный вход. Требование

### 1.2 Какие мутанты сегодняшний блок `w1:296-308` ловит, а какие — нет

Блок `if let Some(a) = fr.as_array() { for r in a { assert_eq!(.., (15_000_000, "bid")) } }`:

| мутант реализации | исход на измеренном кадре | вердикт |
|---|---|---|
| **M-ign** — `view` применён к снимку, к кадрам НЕ применён (14 строк в кадре) | цикл идёт по 14 строкам, первая же `1500000/bid` ≠ `(15000000, bid)` ⇒ **FAILED** | ловится — но только потому, что фикстура СЛУЧАЙНО даёт строки; тест этого не стережёт |
| **M-drop** — транспорт на кадрах обнуляет/вырезает `depth_series` (проекция «ничего не совпало», ветка кадра без строк, `delta.depth_series = []`/отсутствует) | `as_array()` даёт `Some([])` или `None` ⇒ тело цикла не исполняется ⇒ **PASS** | **не ловится — это и есть R4** |
| **M-wrong** — кадр несёт ОДНУ строку, но не ту (`15000000/ask`, `60000000/bid`) | ловится | — |

Критик прав по существу: оракул наблюдает ОТСУТСТВИЕ невыбранных строк, но не ПРИСУТСТВИЕ
выбранной (`testing.md` «Целостность гейта» п.4 — «наблюдает отсутствие, не только сбой»;
«Анти-плацебо» — тест, зелёный на `Ok(())`-подобном пути). Формулировка `C-308` «implementation
that drops every selected depth row … can pass w1» — точна. Формулировка мандата «реализация,
игнорирующая `view` в кадрах, проходит `w1`» — НЕ точна: M-ign ловится (строка 1 таблицы). Разница
важна для правки: нужен не «другой тест», а две недостающие стороны одного — позитивное требование
и сторож того, что кадр ВООБЩЕ нёс глубину.

M-drop — не академический: проекция снимка и проекция кадра идут по РАЗНЫМ структурам
(`Snapshot.series` vs `Frame.delta`), и дев, применяющий `project_view` к кадру через собственную
ветку, легко получает пустой результат на кадре (например, сверяя ключи строк по неканоническому
`band_pct_e8`, который в кадре округлён иначе, чем в снимке) при полностью зелёных проверках снимка.

### 1.3 Точная форма исправления `w1` (A1)

Заменить блок `:299-308` на безусловные утверждения:

```rust
// Кадры — тот же выбор. Первый кадр после дозаписи ОБЯЗАН нести глубину: seq 10 = L2Snapshot@5
// закрывает каденс-интервал 4 (A-054 §1.1 факт 2); pump без событий кадров не даёт (факт 1).
append_book(dir.path(), 5, 3);
let f = next_of(&mut ws, "w1", "frame").await;
let d = &f["data"]["delta"];
assert_eq!(d["cob_observed"], json!(true),
    "SETUP НЕ СОСТОЯЛСЯ: первый кадр после дозаписи не нёс L2-наблюдения — срез глубины не строился: {f}");
let fr = d["depth_series"].as_array()
    .unwrap_or_else(|| panic!("M-100 / П-029: кадр без массива depth_series — проекция вырезала глубину: {f}"));
assert_eq!(fr.len(), 1,
    "M-100 / П-029: кадр обязан нести РОВНО выбранную строку глубины (не 0, не 14): {f}");
assert_eq!((fr[0]["band_pct_e8"].as_i64(), fr[0]["side"].as_str()), (Some(15_000_000), Some("bid")),
    "M-100: кадр несёт не выбранную строку: {f}");
assert!(fr[0]["series"].as_array().is_some_and(|s| !s.is_empty()),
    "M-100: выбранная строка кадра без точек — проекция оставила ключ и выбросила ряд: {f}");
```

Инварианты формы: (а) `len == 1` — одной проверкой закрывает и M-drop (0), и M-ign (14);
(б) `series` непуст — против мутанта «ключ строки есть, ряд пуст»; (в) `cob_observed == true` —
setup-страж, что кадр нёс наблюдение книги (иначе отсутствие глубины было бы законным и тест судил
бы не проекцию). Число точек НЕ пиннить (1…3 в зависимости от того, где лёг тик — факт 3);
`time_s` первой точки пиннить можно (`1752000004`, детерминирован фактом 2), но не обязательно.
Запрещено: оставлять `if let Some(..)`; ждать «кадра с непустой глубиной» циклом — он скрыл бы
M-drop на первом кадре за вторым.

**Независимый контроль (A2) — `w2` получает ветку кадра.** Та же фикстура без `view`: после
`append_book(5, 3)` первый кадр несёт все 14 строк (`sorted == all_rows()`), у каждой ≥ 1 точка.
Это (1) оракул `VB-I-4` на ПРОВОДЕ кадров («без `view` — как раньше»; сегодня `w2` судит только
снимок), (2) контроль для `w1`: он предъявляет исполнением, что фикстура ДАЁТ 14 строк в первом
кадре, и отсутствие строк в `w1` — дело проекции, а не фикстуры. Анти-плацебо в обе стороны:
`w1` падает на «слишком узко» (0 строк), `w2` — на «слишком узко» без выбора.
