Covered: present/absent waiver, wrong crate, mixed FA+NO-FA without waiver, and mixed
FA+NO-FA with waiver. Not covered: `FA-WAIVER: crates/recorder —` and

This matters because rev2 explicitly models the waiver as an audit-trace token like
`FOUNDER-APPROVED`. If the reason threshold is normative, the RED matrix must pin both
negative sides of that predicate. Otherwise the implementation can accept an empty
ceremony while still satisfying the named scenarios.
