## §2. БЛОКЕР Б-1 — ложное зелёное: путь въезжает в push РЕБРОМ ПРЕДКА, минуя ОБА множества; рукотворный дроп благословляется древним токеном

**Где:** `scripts/check_protected_artifacts.sh:167-171` (`fallback_allowed`) в связке с
`born_in_range` (`:124-137`) и `mainline` (`:150-156`); включение fallback'а — `:251`.

**Существо — четвёртый способ, которого мандат требовал искать.** Оба множества круга 3
спрашивают ИМЕНА в деревьях: `born_in_range` — «есть в коммите, нет ни у одного родителя»,
`mainline` — «есть в базе или на first-parent-цепочке». Путь может ПОЯВИТЬСЯ в push'е,
не удовлетворив ни тому, ни другому: **через РЕБРО РОДИТЕЛЯ** — merge-коммит диапазона,
чей второй родитель (старая ветка, форкнутая до архивного переезда) несёт путь. У такого
коммита путь есть и у родителя ⇒ не «рождён»; на first-parent-цепочку он не попадает ⇒
не «магистраль». При этом СОХРАНЕНИЕ пути в этом мерже — рукотворный акт этого push'а
(авто-резолюция вложенного мержа путь бы УДАЛИЛА), и последующий выброс финальным мержем —
тоже рукотворный (авто-резолюция финального мержа путь бы СОХРАНИЛА). Оба акта — дело
диапазона; объясняющего коммита в диапазоне нет; fallback включается и находит древний
токен, к этой потере отношения не имеющий.

**Фикстура F1a** (blob НЕ менялся — идентичен состоянию до древнего удаления; все
setup-guard'ы предъявлены прогоном, `setup=ok`):

```
R0: milestones/M-01.md жив
old-b форк от R0 (+ свой коммит)                    # несёт путь, форк ДО переезда
main: git rm + ALLOW-ARTIFACT-DELETE (ancient); filler → before
feat от before: work; merge old-b --no-commit; git checkout old-b -- M-01.md; commit  # путь СОХРАНЁН при мерже
main: merge feat --no-commit; git rm -f M-01.md; commit                               # путь ВЫБРОШЕН самим мержем
```

Setup-факты (каждый — командой в фикстуре): blob в `c^2` и `c` == blob в `R0` (не менялся);
пути нет на HEAD; в диапазоне НЕТ ни D/R, ни A (`--full-history`); токен — предок базы;
`git merge-tree --write-tree before feat` **содержит** `M-01.md` — авто-merge путь СОХРАНИЛ
БЫ, дроп изготовлен руками.

```
old (origin/main):  exit=1  FAIL milestones/M-01.md: артефакт ИСЧЕЗ с HEAD, и ни один коммит его не удалял   ← ловил
r3  (38a6df7):      push  exit=0  NOTE milestones/M-01.md: ALLOW-ARTIFACT-DELETE в ebef98c                   ← ЛОЖНОЕ ЗЕЛЁНОЕ
                    pull_request exit=0 — та же дыра в обеих прод-формах
```

**F1b** — то же с артефактом, который old-b МЕНЯЛ (m/d на вложенном мерже разрешён
сохранением — живая правка спеки): old exit=1, r3 exit=0 NOTE. Прод-правдоподобие то же,
что у E1 `C-136` (принятого блокером): «разархивировать спеку» через старую ветку, несущую
её, — а затем один evil merge / `-s ours` уносит её беззвучно под древний токен.

**Это регрессия против `origin/main`** (он оба случая валит) и прямое нарушение инварианта
мандата: исчезновение произведено диапазоном (авто-резолюция сохранила бы путь — замер
`merge-tree` выше), объяснено коммитом ВНЕ диапазона.

**Почему это КЛАСС `C-136` Б-1, а не новая причина.** Б-1 круга 1: «fallback благословляет
древним токеном сегодняшнюю потерю» — путь появлялся в диапазоне РОЖДЕНИЕМ. Круг 2 закрыл
рождение-по-диффу, круг 3 — рождение-по-состоянию и магистраль. Б-1 круга 3: путь появляется
в диапазоне РЕБРОМ ПРЕДКА — четвёртое воспроизведение того же класса «предикат fallback'а
недооценивает „появился/изготовлен в этом push'е“». Причина совпадает с `C-136` Б-1.

## §3. Сопутствующие находки (внутри того же класса)

### §3.1 Комментарий барьера снова несёт ложное основание — тот же дефект, что условие 3 `C-136`

`scripts/check_protected_artifacts.sh:157-159`: «Остаётся ровно один случай — путь виден
лишь в деревьях влитых side-веток, унаследованный ими из времён ДО базы. Это и есть
`TD-163`, и только его прошлое вправе объяснять» — **ложно**: F1a удовлетворяет этому
описанию дословно и НЕ является легитимным наследованием.

`:161-165`: «По СОСТОЯНИЮ он неотличим от легитимного `TD-163` … Различить его можно только
СОДЕРЖИМЫМ (blob …)» — **ложно дважды**, предъявлено исполнением
(`/tmp/adv-c3/discr.sh`):

| случай | авто-резолюция дропающего мержа (`git merge-tree --write-tree p1 p2`) |
|---|---|
| F3 — легит `TD-163` | **auto-DELETES** (git сам удаляет; никто ничего не решал) |
| F2 — остаточный случай автора (m/d) | **CONFLICT** (удаление — рукотворная резолюция) |
| F1a — блокер | **auto-KEEPS** (удаление — рукотворный откат авто-результата) |

То есть (а) состояние РАЗЛИЧАЕТ все три случая — тем же семейством запросов к деревьям, на
котором стоит весь барьер; (б) контентная ось, названная автором единственным различителем,
на F1a СЛЕПА: blob идентичен состоянию до древнего удаления — «blob ветки против blob'а на
момент древнего удаления» классифицировал бы рукотворный дроп как чистое наследование.
Ответ на О-8 мандата: остаточный случай описан ЧЕСТНО по намерению (назван, не умолчан),
но «неотличим по состоянию» — неверный факт; названо `COGNITIVE-ONLY`/немеханизируемым то,
что различимо state-запросом. Это не требование строить третью ось (решение founder'а
23.08 в силе) — это требование не фиксировать ЛОЖНОЕ основание в комментарии, по которому
будут приниматься будущие решения (ровно условие 3 `C-136`, повторившееся в новой форме).

### §3.2 M-C не «перекрытый слой»: дифференциальная фикстура ПОСТРОЕНА

Мандат О-4: построить фикстуру, где `^1` и `^@` дают разный вердикт. Построена — это F1a:


## §4. Условие снятия Б-1 — ПО КЛАССУ (урок круга 2 применён)

Не «добавь сценарий F1a». Класс: **fallback не смеет объяснять древним токеном
исчезновение, ИЗГОТОВЛЕННОЕ мержами диапазона.** Легитимно только то исчезновение, которое
авто-резолюция произвела бы и без рук (F3: путь, чисто унаследованный веткой, авто-delete).
Операциональный различитель предъявлен замером §3.1 (авто-резолюция дропающего мержа);
эквивалентное сужение предиката — по выбору architect'а, дизайн не навязываю. Снятие
требует одновременно:

1. F1a-класс (путь входит в push ребром предка: и НЕ рождён, и НЕ в магистрали, и blob
   идентичен древнему) даёт FAIL; фикстура строится ТЕМ способом, каким класс обходят —
   merge-ребро, а не add (`session-handover-2026-08-24.md` §5 п.4);
2. зелёные остаются зелёными: P21/P25, симуляции merge PR #66 и PR #32 (обе формы события,
   0 FAIL), F3-класс чистого наследования;
3. проба несёт сценарий класса (красный против `38a6df7`, зелёный против исправленного) —
   с setup-guard'ами, доказывающими форму (нет A/D/R в диапазоне, blob неизменен, путь у
   второго родителя);
4. комментарии `:157-165` перестают утверждать «ровно один случай» и «различим только
   содержимым» (§3.1) — либо утверждают это с честной оговоркой о F1a-классе;
5. судьба F2-класса (m/d, CONFLICT-ветвь различителя) — решение architect'а/founder'а и
   НЕ входит в условие снятия: named-residual остаётся принятым пределом, пока его
   основание исправлено по п.4.

**Маршрут:** причина Б-1 совпадает с причиной `C-136` Б-1 ⇒ `gates.md` §0 триггер 1 (два
REJECT подряд по одной причине) — АРБИТР, а не четвёртый круг правок вслепую. Вопрос
арбитру методологический: закрываем ли класс сужением предиката (и каким), или фиксируем
границу «имя-уровневый барьер не различает рукотворность» решением founder'а как принятый
предел с TD.

## §6. Наблюдения вне блокера

- **N-1 (M-C)** — см. §3.2: шов `^@` несёт незапиненное поведение.
- **N-2 (reverse merge)** — F5: легит-наследование, влитое мержем с ПЕРВЫМ родителем-веткой

  «магистралью») → r3 exit=1 — ложное красное `TD-163`-класса ОСТАЁТСЯ на этой топологии.
  НЕ блокер: старый барьер там же красен (не регрессия), а прод-путей к такой топологии нет:
  merge в `main` делает только `gh pr merge` (parent1 = main), прямой push закрыт защитой;
  на pull_request CI выезжает на `refs/pull/N/merge`, чей parent1 — база (замерено:
  `git rev-parse refs/pull/66/merge^1` = вершина main-линии, не ветки). Кандидат в TD-строку.
- **N-3 (гигиена проб)** — проба не прибирает свои `mktemp`-песочницы (~30 каталогов за

  `red_docs_freeze` пишет `mktemp` АБСОЛЮТНЫМ шаблоном (`/tmp/red-freeze-*`, `TMPDIR`
  бессилен) и не убирает — на хосте лежало 1430 её исторических каталогов; сегодняшние
  130 (мои два прогона verify + утренние) убраны мной, исторические не тронуты
