**Почему это блокер, а не примечание.** Тезис коммита — «барьер, обходимый токеном на каждом

выбор вердиктов (`:176`) и поиск токена (`:273`, см. B-2). В пробу — сценарий stale-base

коммите НЕ открывает лок на правку гейта, сделанную веткой без собственного токена.

## M-3 (MAJOR). «Названный предел» шире названного: контрабанда без конфликта, и держится она не на `--no-merges`, а на незапинненном дефолте git

**Где:** `scripts/check_gate_meta.sh:260-262` (комментарий «разрешение конфликта, выполненное
В САМОМ merge-коммите»), `:270` (`--no-merges`).

**Достижимость.** Конфликт не нужен: `git merge --no-commit` + правка гейт-класса + `git add` +
`git commit` — произвольная правка, вложенная в merge-коммит, невидима новому барьеру и
ловилась старым:

```
$ bash /tmp/adv-c128-stabs/t2_evil_merge.sh          # новый барьер
 scripts/verify_M-99.sh | 1 +                        # правка РЕАЛЬНО в merge-коммите
VERDICT: PASS — вердиктов проверено: 1, ...
$ bash /tmp/adv-c128-stabs/t2_evil_merge.sh /tmp/adv-c128-stabs/check_gate_meta_OLD.sh
VERDICT: FAIL (1) — ...   exit=1
```

Это не «остаток при разрешении конфликтов», а канал НАМЕРЕННОГО обхода в две команды —
предел принят, но описан уже, чем он есть.

**Механизм не тот, что назван.** Комментарий (`:257-258`) приписывает невидимость флагу
`--no-merges» («снимает merge-of-main, который иначе внёс бы чужое дерево через диф к первому
родителю»). Фактически `git log --name-only` на merge-коммите по дефолту НЕ печатает файлов
(`diff-merges=off`):

```
$ git log --format='' --name-only -1 <merge> | wc -l   → 0
```

Мутация: убрать `--no-merges` — проба зелёная целиком (`VERDICT: PASS (38/38)`), флаг не
запиннен НИЧЕМ; поведение держится на неявном дефолте, который никакой оракул не наблюдает.

**Условие снятия (минимум для MAJOR):** комментарий предела честно называет полный класс
(evil merge / `--no-commit`, не только конфликт); сторож-сценарий фиксирует сам предел
(контрабанда в merge-коммите → сегодня осознанный PASS с этим знанием в тексте сценария) —
иначе предел живёт только в комментарии, который следующая правка снесёт молча.
