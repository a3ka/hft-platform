  (`milestones/M-10-r001-obi-killscreen.md:8-11`).

  (`scripts/verify_M-10.sh:31-55`).

  (`scripts/verify_M-10.sh:54-55`).

Worst case: `research-dev` implements `classify_verdict` and the new report fields enough for
`red_killscreen` to pass, does not run R-001, and `verify_M-10.sh` exits `0` because missing
R-001 remains a `NOTE`. The milestone can then advance without the artifact it was created to
produce.

Required repair:

1. Make missing `research/reports/R-001-obi-trackA.json` and `.md` a `FAIL` for the final M-10
   acceptance gate.
2. If architect wants a pre-report RED-phase mode, split it explicitly, e.g. `verify_M-10.sh --red`
   vs final default fail-closed mode. The default used by dev Done Block must require the report.

  (`milestones/M-10-r001-obi-killscreen.md:37-38`).
