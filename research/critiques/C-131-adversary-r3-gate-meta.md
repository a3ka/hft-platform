## N-1 (minor). Подделка `GITHUB_SHA` — не новая поверхность, но предел в §2bis не назван

Форга `GITHUB_SHA=$(git rev-parse HEAD)` на sync-вершине включает якорь и возвращает
молчание суда («вердиктов проверено: 0» — воспроизведено исполнением), однако строка
активации печатается (аудит-след), а мощность атаки НЕ выше уже существующей тривиальной:

```
$ EVENT_NAME=push PUSH_BEFORE=$(git rev-parse HEAD) bash check_gate_meta.sh   # без всякой форги
VERDICT: PASS — вердиктов проверено: 0                    ← пустой диапазон честным входом
```

Весь входной контракт барьера (EVENT_NAME/PR_BASE_SHA/PUSH_BEFORE) декларативен, и лжец
имел тривиальный PASS до этой правки. Дыры нет; но §2bis, называющий пределы («ЧЕСТНО О
ПРЕДЕЛЕ ПРОБЫ»), о декларативности `GITHUB_SHA` молчит — одной строки достаточно.

## N-2 (minor). Конъюнкт «равенство», в отличие от «непустоты», отдельно не запиннен

`GM-16g` пиннит «`GITHUB_SHA` пуст ⇒ якорь выключен». Мутация «равенство → true при
сохранённой непустоте» переживает пробу: наблюдаемое расхождение требует непустого
`GITHUB_SHA ≠ HEAD`, чего при дефолтном `actions/checkout` не бывает (проверено логом
реального прогона: чекаут — ровно `GITHUB_SHA`). Форма становится живой, если в джоб
когда-нибудь добавят `ref:` (чекаут вершины ветки при GITHUB_SHA=merge-ref) — тогда якорь
обязан выключиться, и именно равенство это держит. Не блокер (недостижимо при текущей
проводке — `.github/workflows/ci.yml:274-285`, `checkout@v4` без `ref:`); строка-оговорка
в §2bis рядом с пределом `EVENT_NAME` — достаточно.

## N-3 (minor). «Ложный красный» из тела коммита на названном реплее не наблюдаем — наблюдаема только его предпосылка

Тело `0302b0f`: «Замер на merge-ref PR #60 ... диапазон давал 2 пути вместо 1 — ложный
красный». Реплей (merge `a41a736` в `92f6e65`, база `37d9697`) подтверждает ПОЛОВИНУ: cc на
merge-ref действительно печатает `scripts/verify_design_claims.sh` (лишний путь —
воспроизведено), но красного из него не выходит НИ НА ОДНОЙ редакции: единственный судимый
вердикт диапазона — `R-109`, он REJECT, лок не применяется (`C-130` §П фиксирует PASS этого
же реплея и у `e88dfe9`). Ложный красный этого класса требует ПРОХОДНОГО вердикта — форма
предъявлена исполнением в Б-1. Дефект реален, фикс верен; неточна только атрибуция замера
в теле коммита. Записи достаточно — код правки не требуется.
