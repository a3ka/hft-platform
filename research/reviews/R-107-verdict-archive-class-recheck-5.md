`declared_dirs()` (`scripts/tests/red_verify_design_claims.sh:713-718`) собирает из строки

(`:698-699`, `:744-745`). Регулярка (а) МОЛЧА РОНЯЕТ имя без завершающего слэша, с точкой,
с не-ASCII символом — переобъявление таким именем безнаказанно; (б) НОРМАЛИЗУЕТ вложенный
путь к родителю (`research/reviews/sub/` → `research/reviews/`) — недообъявление вложенным
путём безнаказанно. Свидетели, каждый: **проба 67 PASS / 0 FAIL, exit=0**, а на реальном
дереве INFO лжёт при `VERDICT: PASS`:

   исключённым. Стаб взят ДОСЛОВНО из условия APPROVED `R-103`, где ему предписано гибнуть.
2. **S1** — `research/reviews/` печатается как `research/reviews/sub/`: INFO утверждает, что
   исключён только подкаталог, т.е. **96 файлов** верхнего уровня `research/reviews/`

### Конечность: закрытие в один шаг, и после него поверхности нет

Спираль всех пяти кругов — один и тот же механизм: ассерт на СУЖАЮЩЕМСЯ ПРОКСИ (счётчик →
перечень грепов → образ регулярного извлечения). Терминальная форма — убрать прокси:
сравнивать МНОЖЕСТВО СТРОК `V-АРХИВ` вывода гейта с ОЖИДАЕМОЙ СТРОКОЙ-КОНСТАНТОЙ целиком,
строковым равенством (константа в сценарии строится из `want`; для V-4 и V-7 они отличаются
только списком). Тогда ЛЮБОЕ наблюдаемое отклонение — имя в любом написании, слэш, точка,
вложенность, дубль, порядок, проза, вторая строка — есть неравенство строк; NC1ns, S1,
S1all, S2, S3 и все десять прежних гибнут об один ассерт. Остаток — РОВНО два предела,
уже названные `R-103` F-2/F-3 (экстенсионально тождественная копия носителя; пустой
каталог класса): они недоступны чёрному ящику в принципе и предъявляются докстрокой.
Шестого адверсарного круга по этой поверхности после равенства СТРОКИ не существует —
у наблюдателя один канал, и он оказывается покрыт весь. Механизм цену оправдывает; пятый
круг оплачен не новой поверхностью, а заменой принятой конструкции более слабой. Форма —
за ведущим architect'ом (`gates.md` §4, граница reviewer↔architect); исправление по
вердикту требует оракула (`testing.md`).
