### `M-73` — офсайт-копия по расписанию

Четыре круга (`R-151` → `R-155` → `R-157` → `R-158` APPROVE). Код в `main` (`7581f60`) и на
проде; **первый и второй АВТО-прогоны подтверждены**.

**Самая ценная находка круга 3 — сторож сбоя источника был мёртв.** Присваивание сбрасывает
`PIPESTATUS`, и следующая строка читала статус самого присваивания:

```
false | true ; a=${PIPESTATUS[1]} ; b=${PIPESTATUS[0]}   → a=0 b=0
false | true ; st=("${PIPESTATUS[@]}")                   → st=(1 0)
```

Следствие: `find` падает, `rsync` выходит нулём, обёртка пишет «ОК», ставит отметку успеха,
гасит тревогу — **не скопировав ничего**. Ровно то состояние, которое милестоун объявил
недопустимым. Закрыто фиксом dev'а + оракулом architect'а
(`scripts/tests/red_offsite_pipeline_rc.sh`), который исполняет конвейер прод-формой.
