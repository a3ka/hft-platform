# Инвентарь невлитых веток — 2026-08-19 (§B плана)

**Предмет:** 23 ветки `origin` помимо `main` на `080d7b3`. Исполнение §B
`docs/plans/plan-branches-and-ci-2026-08-19.md`.

**Что это и чем НЕ является.** Это НЕ новый аудит и НЕ новые решения. Правило предшественника
(`docs/workflow/reading-map.md` §2): по большинству веток решение уже вынесено — аудитом
13.08, арбитражем `A-010`, вердиктами кругов или прямым решением founder'а. Работа состояла в
том, чтобы **найти уже принятое, проверить исполнением, что оно не устарело, и назвать
исполнителя**. Ни одного механизма здесь не строится.

**Метод.** По каждой ветке: `git rev-list --left-right --count`, `--diff-filter=A` по
three-dot, `git merge-tree --write-tree`, `gh pr list/checks`, `gh run list`. Поглощение
доказывается **ancestry** (`git merge-base --is-ancestor`) либо **сравнением содержимого**
(`diff` тел), а НЕ совпадением путей. Пять чтецов первоисточников работали параллельно;
каждое утверждение, на котором стоит рекомендация «удалить» или «влить», перепроверено
лично — три их вывода при этом оказались неверны и заменены (§5).
