## 2. Кто и как сериализует кадр на провод (путь по коду)

```
reduce_event_stream ──► frames_since(dir, filter, sel, after, max)      crates/gateway/src/lib.rs:1819
                          └─ vec![Frame::versioned(after, cursor, delta, at_ms)]   :1833
gateway-serve pump (spawn_blocking, тик PUSH_INTERVAL_MS = 250)          crates/gateway-serve/src/lib.rs:945,1241,1302
  v1-путь:   wire_v1::frame_msg(&id, &frame)                             :1112, :1422
               └─ json!({"type":"frame","v":1,"sub":id,"data":serde_json::to_value(frame)})
                                                                          crates/gateway-serve/src/wire_v1.rs:181-184
               └─ serde_json::to_string(..) → Message::Text → WS
  legacy:    ServeMsg::Frame(frame) → serde_json (GS-I-4/GS-I-5)         crates/gateway-serve/src/lib.rs:143,1461
```

Два факта, существенных для развилки:

1. **Конверт уже несёт `sub`** — идентификатор подписки на каждом сообщении v1. Карта
   `sub → Selector` есть у клиента (он сам её послал в `subscribe`). То есть для ПРОДУКТА
   атрибуция кадра инструменту выводима на стороне клиента; невыводима она для ОРАКУЛА,
   сверяющего содержимое, и для стороннего наблюдателя трафика.
2. **Тик пуша — 250 мс, не 100** (мандат называл 100): `PUSH_INTERVAL_MS: u64 = 250` —
   `crates/gateway-serve/src/lib.rs:945` (legacy), `:1241`/`:1302` (v1). Максимум 4 кадра/с
   на подписку, и только при росте журнала (heartbeat удалён, Б-3 `d7c1691`).

**Слепота `o9` — механическая, подтверждена чтением ассерта**
(`crates/gateway-serve/tests/red_ws_session.rs:892-899`): проверка —
`!a_body.contains("ETHUSDT")` по сериализованному хвосту соединения A. Строка `"ETHUSDT"`
в JSON кадра не встречается ПО ПОСТРОЕНИЮ (см. §1), значит ассерт не может покраснеть от
кадров чужого инструмента никогда. Зонд architect'а (13 тиков чужого при зелёном оракуле) —
следствие, не случайность.

## 3. Развязка Р-А — расширить форму кадра (`venue`+`symbol` или `selector` в `Frame`)

Статус формы: **T-designate, не T1** (`docs/05-contract-layer.md` §2) — меняется аддитивно
с bump'ом версии, без contract-RFC.

### 3.1 Что ломается / что бампается (замер по потребителям)

```
$ git grep -n "Frame" origin/feat/M-65-ws-session -- 'crates/*/src/*.rs'   # вне tungstenite/journal-омонимов
```

- **Потребители формы**: `crates/gateway` (producer + `Snapshot::apply` `:1338` + свои тесты),
  `crates/gateway-serve` (`lib.rs`, `wire_v1.rs`, legacy `wire`), `wsprobe` (legacy `ServeMsg`).
  Больше НИКТО в workspace (`SM-*` — оракулы sim'а, `Frame` не потребляют; совпадение имени
  `LargeFrameVerifier` в journal — не связано).
- **Компиляционно** внешних конструкторов нет (`Frame::versioned` приватен) — правка замкнута
  в `crates/gateway/src/lib.rs`: struct + `versioned` + 5 call-site'ов §1.
- **Сериализация**: `deny_unknown_fields` в workspace один — `research-cli/strategy_cell.rs:32`,
  к кадрам отношения не имеет. Старые консюмеры новый ключ проигнорируют; новый консюмер на
  старом кадре потребует `#[serde(default)]` — по `VB-I-6` это **defensive-default, НЕ
  совместимость**: консюмер обязан гейтить на `schema_version`.
- **Bump** `GATEWAY_SCHEMA_VERSION` **8→9** (паттерн VB-I-11: 7→8). Тянет за собой:
  - `crates/gateway/tests/red_gateway_schema_version.rs` — пиннит константу тремя
    runtime-ассертами, правится в том же изменении (architect-zone);
  - **чекпоинты прода инвалидируются**: `read_and_validate` гейтит
    `gw_v != GATEWAY_SCHEMA_VERSION → None` (`lib.rs:2742-2746`) — по конструкции «файл
    прошлой версии — кэш, не ошибка», следует холодный rebuild; цена названа в коде — до
    чекпоинта холодный снапшот на проде стоил **409.74 s** (`gateway-serve/src/lib.rs:97`);
  - `GS-I-4`/`GS-I-5` (`red_serve_passthrough.rs`) — переживают: roundtrip и passthrough
    сравнивают обе стороны, посчитанные одним кодом; `o5_bounded_window_shrinks_ws_payload`
    сравнивает размеры ОТНОСИТЕЛЬНО (обе стороны получают одинаковую прибавку).

### 3.2 Цена в байтах (посчитано, тик 250 мс)

| вариант | B/кадр | на активную подписку/сутки | масштаб §16 (10 000 conn × 16 sub) |
|---|---|---|---|
| `venue`+`symbol` (`,"venue":"Binance","symbol":"BTCUSDT"`) | 37 | 12.8 MB | **2.05 TB/сутки ≈ 189 Мбит/с** |
| весь `selector` | 104 | 35.9 MB | 5.75 TB/сутки ≈ 532 Мбит/с |

Верхняя граница (кадры идут только при событиях), но на активном рынке это и есть режим.
**Контекст, который нельзя не назвать: этот же milestone только что ОТКЛОНИЛ heartbeat ценой
≈100 Мбит/с как «нижнюю границу всего бюджета §16 на реальные данные»** (§4.2bis, Б-3).
189 Мбит/с постоянной избыточности — тот же класс аргумента, при том что `sub` на конверте
уже даёт клиенту атрибуцию бесплатно.

### 3.3 Процессная цена, которой у Р-Б нет

`milestones/M-65-ws-session.md` §2: **`crates/gateway/src/**` — Forbidden ВСЕМ** («M-65 не
трогает расчёт серий»), §2 же: «Contract impact: нет». Р-А внутри M-65 невозможна без правки
нормативных секций спеки (Forbidden paths, contract impact) — это всегда критик
(`gates.md` §9), либо отдельный milestone на смену формы. Плюс FA-правка (`docs/fa/viz-backend.md`
VB-I-6/VB-I-11 — строка о bump'е 9).

### 3.4 Чем новый оракул краснеет против дефекта «чужой инструмент 13 тиков»

Ассерт: `frame.data.symbol == селектор, который клиент послал в subscribe` (и venue).
Мутант `crosstalk` качает pump'ом чужой селектор → штамп в кадре (проставленный в
`frames_since` из РЕАЛЬНОГО входа редьюсера, §1) несёт чужой символ → неравенство → красный.
**Не проверено исполнением** (поля не существует; проверка требовала бы impl-правку —
вне зоны и вне круга). Остаточная слепота: штамп — самоаттестация; рефакторинг, взявший
символ не из входа редьюсера, а из реестра подписок, вернёт слепоту молча — против подделки
самого штампа ассерт по штампу не защищает по построению.

## 4. Развязка Р-Б — инвариант сессии на существующих типах (оракул, не форма)

Форма: **«кадры сессии продолжают её снапшот»** — якорь: селектор, который КЛИЕНТ послал в
`subscribe` (сильнее, чем `Snapshot.selector`: не самоаттестация сервера); механика:
`Snapshot::apply` полученных кадров + сверка с независимым эталоном
`gateway::snapshot(dir, filter, sel_клиента, Cursor::at(to))`.

### 4.1 Проверено ИСПОЛНЕНИЕМ, не рассуждением

Зонд `probe_axis7.rs` (текст — приложение A), detached-worktree `af0f634`,
`cargo test -p gateway --test probe_axis7`:

```
running 2 tests
test q1_q2_q4_alien_frames_diverge_from_reference_when_victim_is_silent ... ok
test q3_alien_frames_diverge_when_both_instruments_grow ... ok
test result: ok. 2 passed; 0 failed; ... finished in 0.07s
```

| вопрос | исход |
|---|---|
| **q1** легитимная сессия: `snapshot(C) ⊕ frames(C..to)` ≡ независимый `snapshot(sel, to)` | **сходится бит-в-бит** — инвариант достижим на существующих типах |
| **q2** сценарий зонда «13 тиков»: жертва молчит, растёт чужой; кадры накачаны чужим селектором | **расходится** — оракул краснеет ровно против показанного дефекта |
| **q3** растут оба инструмента (смешение при живой жертве) | **расходится** |
| **q4** чужой кадр сцепляется с курсором сессии (`from == C`) | **сцепляется** — seq-пространство общее; курсорная цепочка инструмент НЕ пиннит, проверка обязана быть по СОДЕРЖИМОМУ |

Анти-плацебо зонда встроено: q1 (обязан быть равен) и q2 (обязан быть НЕ равен) бегут на
одной фикстуре — исход «всё всегда расходится» исключён контролем q1.

### 4.2 Какие поля дают связь кадра с сессией

`sub` на конверте (принадлежность подписке) + `from`/`to` (позиция в потоке; q4 — для
атрибуции инструмента бесполезны) + СОДЕРЖИМОЕ `delta` против независимого эталона
(единственный носитель инструмента). Wire-JSON десериализуется обратно в типы —
`GS-I-4` roundtrip это уже пиннит.

### 4.3 Не пиннит ли Р-Б ветку исполнения вместо свойства (класс `R-056` Б-4 / `A-005` §6)

Три довода, все проверяемые:

1. **Форма уже канонизирована in-tree на legacy-пути**: `o3_frames_converge_to_latest`
   (`red_ws_protocol.rs:229-278`) делает буквально это — принимает WS-кадры, `acc.apply(&f)`,
   сверяет с `gateway::snapshot(LATEST)` при совпадении курсоров. Р-Б — та же
   эквивалентность, параметризованная селектором подписки. Прошла критика/ревью как свойство,
   не как ветка.
2. Инвариант не фиксирует нарезку кадров (любая декомпозиция, сходящаяся к эталону,
   легальна), не запрещает свежий `Snapshot` посреди сессии (оракул переякоривается) и не
   требует конкретного кода pump'а.
3. Сходимость `apply`-пути к полному снапшоту — уже sacred (GW-I-4/VB-I-2); Р-Б не добавляет
   нового ограничения на реализацию, только адресует существующее ПО ПОДПИСКЕ.

### 4.4 Чем краснеет и что тянет за собой

- `o9` переписывается с `!contains("ETHUSDT")` на «кадры сессии A сходятся к эталону
  селектора A»; батарея: `crosstalk`/`connshare` попадают в kill-set `o9` содержимым, а не
  строкой. **Деталь фикстуры, найденная замером:** при дозаписи ТОЛЬКО жертвы мутант
  `crosstalk` умирает молчанием (у чужого селектора нет событий → pump пуст → ловит ассерт
  «A замолчало») — падение по неверной причине; kill-фикстура обязана растить ОБА
  инструмента (q3), чтобы краснеть именно содержимым.
- Формы, версии, чекпоинты, провод, FA — не тронуты. Bump не нужен. Зона — целиком
  architect (`crates/gateway-serve/tests/**` — Allowed в M-65; `gates.md` «исправление по
  вердикту тоже требует оракула» здесь удовлетворено тем, что исправление и ЕСТЬ оракул).
- Остаточная слепота, названная честно: провод ОСТАЁТСЯ инструмент-слепым для стороннего
  наблюдателя (tcpdump/wsprobe без карты `sub→selector` кадр не атрибутирует). Это дефицит
  наблюдаемости ПРОДУКТА, не оракула — если он ценен, это отдельный предмет (TD/milestone
  формы), не условие закрытия оси 7.

## 5. Рекомендация (помечена как рекомендация; выбор за architect'ом)

**Для закрытия дыры оси 7 и разблокировки задачи 9 — Р-Б.** Основания-замеры: инвариант
достижим и ловит показанный дефект исполнением (q1–q3); прецедент формы уже in-tree (o3);
нулевая цена на проводе против 189 Мбит/с у Р-А при только что отклонённом heartbeat'е того
же класса; зона и milestone не расширяются, тогда как Р-А требует правки Forbidden-секции
спеки (всегда критик) либо отдельного milestone. Р-А при этом НЕ закрывает того, что не
закрывает Р-Б (атрибуция для стороннего наблюдателя — самоаттестационный штамп слабее сверки
содержимого, §3.4), поэтому «сделать обе» не даёт суммы, оправдывающей двойную цену сейчас;
если наблюдаемость провода понадобится фронту/ops — это отдельная аддитивная форма со своим
bump'ом, и решение о ней не обязано приниматься в этом круге.

## 6. Что НЕ смог измерить и почему

1. **Р-А исполнением** — поля не существует; замер потребовал бы impl-правку
   `crates/gateway/src/**` (вне зоны architect вовсе и Forbidden в M-65). §3.4 — статический
   разбор, не прогон.
2. **Реальная частота кадров на проде** — 4 Гц это потолок тика; фактическая плотность
   зависит от рынка, v1-путь на прод не выкачен, а legacy-замер через `wsprobe` упирается в
   его же сломанность (`TD-118`/`TD-122`). Цифры §3.2 — верхняя граница.
3. **Зонд родителя (13 тиков) не перепрогонял** — его текста в ветке нет; воспроизведён
   КЛАСС дефекта на уровне библиотеки (q2), не тот самый прогон.
4. **Поведение o5_bounded_window_shrinks_ws_payload под +37 B** — прочитан как относительное
   сравнение, прогоном под Р-А не проверялся (Р-А не реализовывалась).

## Приложение A — текст зонда (не оракул; не закоммичен в крейты)

Файл: `crates/gateway/tests/probe_axis7.rs` на detached-worktree `af0f634`
(`origin/feat/M-65-ws-session`), прогон: `cargo test -p gateway --test probe_axis7` → exit 0.

```rust
//! ЗОНД (architect-clone, разведка развилки M-65 ось 7) — НЕ оракул, НЕ коммитится.

use contracts::{to_fixed, DataSource, EventKind, Level, MdPayload, Side, Venue};
use gateway::{frames_since, snapshot, Cursor, Selector};
use journal::{EpochFilter, Journal, WriterConfig};
use std::path::Path;

const BASE_MS: i64 = 1_700_000_000_000;
const MAX_EVENTS: usize = 1_000_000;

fn lvl(px: f64, qty: f64) -> Level {
    Level { price: to_fixed(px), size: to_fixed(qty) }
}

fn writer_cfg() -> WriterConfig {
    WriterConfig {
        max_segment_bytes: 64 * 1024,
        min_free_bytes: 0,
        source: DataSource::OwnCapture,
        provenance: "m65-probe".to_string(),
        epoch_id: "own-test".to_string(),
    }
}

fn sel_of(symbol: &str) -> Selector {
    Selector {
        venue: Venue::Binance,
        symbol: symbol.to_string(),
        timeframe_ms: 1_000,
        bands: vec![0.001],
        window_ms: Some(60_000),
    }
}

/// Та же фикстура, что в red_ws_session.rs: ДВА инструмента, иначе изоляция непроверяема.
fn seed(dir: &Path) {
    let mut j = Journal::open_with(dir, writer_cfg()).expect("open_with");
    for (sym, px) in [("BTCUSDT", 65_000.0), ("ETHUSDT", 3_000.0)] {
        j.append(EventKind::md(Venue::Binance, sym, MdPayload::L2Snapshot {
            bids: vec![lvl(px, 2.0)],
            asks: vec![lvl(px + 10.0, 1.5)],
            ts_exch_ms: BASE_MS,
        })).expect("append snapshot");
        for k in 0..8i64 {
            j.append(EventKind::md(Venue::Binance, sym, MdPayload::Trade {
                price: to_fixed(px + k as f64),
                size: to_fixed(0.1),
                side: Side::Buy,
                ts_exch_ms: BASE_MS + k,
            })).expect("append trade");
        }
    }
    j.flush().expect("flush");
}

fn append_more(dir: &Path, symbol: &str, n: i64, from_ms: i64) {
    let mut j = Journal::open_with(dir, writer_cfg()).expect("reopen journal");
    for i in 0..n {
        j.append(EventKind::md(Venue::Binance, symbol, MdPayload::Trade {
            price: to_fixed(100.0 + i as f64),
            size: to_fixed(0.5),
            side: Side::Sell,
            ts_exch_ms: from_ms + i,
        })).expect("append more");
    }
    j.flush().expect("flush more");
}

/// q1 + q2 + q4: жертва (BTC) МОЛЧИТ, растёт только чужой (ETH) — сценарий «13 тиков».
#[test]
fn q1_q2_q4_alien_frames_diverge_from_reference_when_victim_is_silent() {
    let dir = tempfile::tempdir().expect("tempdir");
    seed(dir.path());
    let sel_btc = sel_of("BTCUSDT");
    let sel_eth = sel_of("ETHUSDT");
    let filter = EpochFilter::OwnCaptureOnly;

    let snap_c = snapshot(dir.path(), filter.clone(), &sel_btc, Cursor::LATEST).expect("snapshot C");
    assert!(!snap_c.series.ohlcv.is_empty(), "setup-guard: снапшот BTC пуст");

    append_more(dir.path(), "ETHUSDT", 13, BASE_MS + 2_000);

    let (frames_alien, cur_alien) =
        frames_since(dir.path(), filter.clone(), &sel_eth, snap_c.cursor, MAX_EVENTS)
            .expect("frames alien");
    assert!(!frames_alien.is_empty(), "setup-guard: чужих кадров нет — дефект не смоделирован");

    // q4: чужой кадр ПРОДОЛЖАЕТ курсор сессии BTC.
    assert_eq!(frames_alien[0].from, snap_c.cursor, "q4");

    // q2: «snapshot ⊕ чужие кадры» ОБЯЗАНО разойтись с независимым эталоном.
    let mut merged = snap_c.clone();
    for f in &frames_alien { merged.apply(f); }
    let reference =
        snapshot(dir.path(), filter.clone(), &sel_btc, cur_alien).expect("reference");
    assert_ne!(merged.series, reference.series, "q2 ПРОВАЛЕН: дефект не пойман");
```
