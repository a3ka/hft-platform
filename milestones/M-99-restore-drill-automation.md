## 1. Objective

Офсайт-копия журнала проверяется на читаемость АВТОМАТИЧЕСКИ раз в месяц — выборка «первый /
средний / последний индекс» скачивается с Storage Box в отдельный каталог и читается прод-читателем,
итог пишется в файл состояния. Провал, просрочка или отсутствие проверки видны: (а) метрикой
`backup_restore_drill_ok` в `/metrics` recorder'а; (б) тревогой `WD-RESTORE-DRILL` сторожа
`ops-watchdog` — единственного наблюдателя, который на проде реально исполняется.

```rust
pub const RESTORE_DRILL_FRESH_WINDOW_MS: i64 = 40 * 24 * 60 * 60 * 1000;
pub const DEFAULT_RESTORE_DRILL_STATE: &str = "/var/lib/hft/journal-restore-drill.json";

Incident::RestoreDrill                       // code() == "WD-RESTORE-DRILL"; уровень Critical

// crates/ops/src/watchdog_cycle.rs — аддитивно, `CycleInputs` не меняется
pub fn run_cycle_with_drill(inputs: &CycleInputs, serving: &ServingInputs,

// run_cycle_full(..) ≡ run_cycle_with_drill(.., None, ..)

// crates/ops/src/bin/ops-watchdog.rs — env `WATCHDOG_RESTORE_DRILL_STATE`
// (дефолт DEFAULT_RESTORE_DRILL_STATE); бинарь зовёт run_cycle_with_drill(.., Some(&verdict), ..)

// crates/recorder/src/metric_emit.rs — сигнатура M-74 НЕ меняется

// ≡ set_gauge("backup_restore_drill_ok", verdict.is_ok() as 0|1) — ВСЕГДА, на каждой ветке
```

| вход | вердикт |
|---|---|
| файла нет / не читается / это каталог | `Missing` |
| JSON не разобран (в т.ч. обрывок); нет обязательного поля; `ok=1` без 64-hex `digest` | `Unparseable` |
| `ok != 1` | `Failed` |
| `events_read == 0` или поля нет | `Empty` |
| `ts_wall_ms > now` | `FromFuture` |
| `now − ts_wall_ms > RESTORE_DRILL_FRESH_WINDOW_MS` | `Stale` (ровно на границе — ещё `Ok`) |
| иначе | `Ok` |

Порядок проверок в таблице — порядок приоритета: первое сработавшее условие и есть вердикт.

**Первое включение.** До первого прогона файла нет ⇒ сторож поднимает `WD-RESTORE-DRILL` на каждом
такте (дедуп — общий). Первый прогон исполняется ВРУЧНУЮ сразу после деплоя (задача 8) — окно
тревоги короткое и намеренное: отсутствие проверки — тревога, а не норма.
